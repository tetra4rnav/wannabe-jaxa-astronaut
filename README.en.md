# Unofficial JAXA astronaut-applicant wiki

[日本語](./README.md)

This repository is **not an official site of JAXA, NASA, ESA, or any other space agency.** For applications and official procedures, use each agency’s own pages.

## Who it is for

A study site for people who want to become JAXA astronauts, and for anyone learning Japan’s human spaceflight record from primary official sources. It is not an application desk and not a breaking-news outlet.

## How to read it

- **Wiki** pages cite only allowlisted official primary sources. Wikipedia, journalism, blogs, social media, and secondary explainers are not wiki citations.
- **News** comes from official feeds and official X accounts. Read items not only by recency, but in the timeline of the related program or project.
- **Humans write the wiki.** An LLM proposes which pages to add or change, and periodically audits claims. It does not generate or rewrite wiki bodies.

## Four-stage loop

Official news is collected and shown in the chronological context of the related project. An LLM proposes wiki additions or edits, grounded in earlier official material from that same project. A person writes Markdown and cites official URLs. An LLM fact-checks body against sources; findings go to an audit history, and humans make the edits.
